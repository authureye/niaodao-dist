# 鸟岛 · 安装包

X 岛的第三方 Android 客户端，这个仓库只放安装包和更新信息，源码不在这里。

**这不是 X 岛官方应用，不受官方支持。** 所有串、回复、图片都来自 X 岛
（https://www.nmbxd1.com），版权属 X 岛及原作者；官方域名变更时以官方为准。

## 下载与安装

1. 进 [Releases](https://github.com/authureye/niaodao-dist/releases/latest)，下最新的
   `niaodao-v*.apk`；
2. 点开安装，Android 会提示「允许此来源安装应用」，同意后才能装；
3. 覆盖安装不会丢数据（书签、阅读进度、屏蔽、登录身份都在本机）。

系统要求：Android 8.0 及以上。

## 第一次打开

会有一个不能跳过的说明页，逐条列出除 X 岛以外还会连接哪些服务器、发什么内容、本机留什么，
同意后才开启联网功能。选「不同意」也能正常看串、发串、搜索、用书签和图片墙，
只是天气、翻译、AI 总结和在线检查更新保持关闭，之后可以在「我的 → 第三方服务与数据」里改。

## 主要功能

- **看串**：版块、时间线、订阅三种入口；楼层支持引用跳转、剧透折叠、骰点判读、图片点击放大；
- **发串与回复**：支持贴图、颜文字、骰子、防剧透，发完可以自动跳到自己那一楼；
- **书签**：给某一层加书签，点开就回到收藏的那一页那一层；
- **阅读进度**：重新打开一串自动回到上次停下的位置；
- **本地搜索**：搜索已浏览并缓存到本机的正文，浏览得越多搜到的越多；
- **图片墙**：把一串里的图片集中起来看，可长按保存到相册；
- **图片识字**：识别图片里的文字，模型随包安装，整张图在本机处理，不上传；
- **朗读**：调用系统语音引擎念正文，离线；
- **翻译**：外语楼层下方点「译为…」，译文缓存在本机；
- **AI 总结**：自己填服务商和密钥后，可以在串页一键整理长串（默认关闭）；
- **天气**：可选。在「我的 → 天气」开启并选城市（不读定位），主页显示当前与未来三天，
  发串回复时可勾选「附带天气」在正文末尾带上一行；
- **屏蔽**：关键词、用户、串号三种，只对当前设备生效；
- **导出**：把一串导出成纯文本或 Markdown，用系统分享存到本机。

## 自动更新

客户端「我的」页有「检查更新」，后台每天查一次，有新版本会在底部标签点一个红点提示，
不会弹窗打断看串。`update.json` 是给客户端读的版本信息，手动下载用不到。

## 除 X 岛之外还会连哪些服务器

| 服务 | 用途 | 发送内容 | 本机留存 |
| --- | --- | --- | --- |
| GitHub（github.com、api.github.com、raw.githubusercontent.com、cdn.jsdelivr.net） | 查新版本、下载安装包 | 只带当前版本号 | 上次检查时间 |
| open-meteo.com | 当前天气与三天预报（默认关闭） | 你在设置里选的城市经纬度（默认北京，不读定位） | 不落盘；取到后半小时内复用，卡片底部显示更新时刻 |
| 翻译服务（transmart.qq.com、api.mymemory.translated.net、lingva.ml、translate.googleapis.com） | 点「译为…」时翻这一层 | 该层纯文字（引用号、剧透、骰点、链接先摘掉） | 译文缓存、每日次数 |
| 你自己填的 AI 服务商（默认 api.deepseek.com） | 点「总结」时整理长串 | 当前串已加载到本机的楼层正文 | API Key 只在本机 |
| X 岛官方接口（api.nmb.best、image.nmb.best） | 看串、发串、回串、取图 | 就是 X 岛本身 | 本地缓存 |

这些请求都由你的设备直接发出，不经过作者服务器；不含饼干，也不含浏览记录。
第三方会按它们自己的规则记录请求（如 IP、时间、内容），留存多久由它们决定，
**其数据安全既不由 X 岛保证，也不由本客户端保证**。

## 关于饼干

X 岛不使用账号密码，身份就是一串叫「饼干」的字符串。登录方式：扫二维码或从相册选二维码，
也可以直接粘贴二维码里的文字。饼干等同于密码，只保存在本机，不会随图片等外部请求发送。

## 使用边界

- 不做整岛采集，不做对外分享的检索服务；本地搜索只搜你自己浏览过的缓存；
- 不代理、不桥接、不合并 X 岛与第三方的数据，界面表达对齐网页版；
- 请求按需要发、带明确标识，不给 X 岛服务器添负担；
- 客户端里的任何浏览辅助都只服务于你自己看串，不得用于针对他人。

## 遇到问题

- 打不开、一直转圈：先确认 X 岛当前域名在浏览器里能打开，再下拉刷新；
- 提示签名不一致装不上：先卸载旧包再装（会清掉本机数据）；
- 想装旧版本：这里只保留最新一版，旧版本不再提供下载。
